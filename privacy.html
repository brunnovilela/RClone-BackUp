Política de Privacidade / Privacy Policy

Última atualização / Last updated: 2026-10-05

Português

O app rclone-backup é uma ferramenta privada, usada exclusivamente pelo seu dono para fazer backup das suas próprias contas do Google Drive.

  • Dados acessados: arquivos e metadados do Google Drive das contas do próprio dono, em modo somente leitura (escopo drive.readonly).
  • Uso: os dados são copiados apenas para um disco local de propriedade do dono, com a única finalidade de backup.
  • Compartilhamento: nenhum dado é compartilhado, vendido ou transferido a terceiros.
  • IA: nenhum dado é usado para treinar modelos de inteligência artificial ou aprendizado de máquina.
  • Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

English

The rclone-backup app is a private tool used solely by its owner to back up the owner's own Google Drive accounts.

  • Data accessed: Google Drive files and metadata of the owner's own accounts, read-only (drive.readonly scope).
  • Use: data is copied only to local storage owned by the owner, for backup purposes only.
  • Sharing: no data is shared with, sold to, or transferred to any third party.
  • AI: no data is used to train artificial intelligence or machine learning models.
  • Revocation: access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
