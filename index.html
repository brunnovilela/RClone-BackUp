rclone-backup

PT: rclone-backup é uma ferramenta de uso pessoal e privado. Ela faz cópias de segurança dos arquivos do Google Drive do próprio dono para um disco local, usando o software de código aberto rclone. Não é um serviço oferecido ao público.

EN: rclone-backup is a private, personal-use tool. It backs up the owner's own Google Drive files to local storage using the open-source software rclone. It is not a service offered to the public.
